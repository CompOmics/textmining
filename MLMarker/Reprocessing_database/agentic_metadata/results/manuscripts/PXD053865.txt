PRIDE PROJECT PROPERTIES:
organisms: Homo sapiens (human)
organism parts: Cell culture
instruments: Orbitrap Eclipse
modifications: iodoacetamide derivatized residue
experiment types: Bottom-up proteomics; Data-dependent acquisition
keywords: Sars-cov-2; cysteine-reactive compounds; proteostasis; orbitrap eclipse: sp3; faims

ABSTRACT:
proteomics experiments performed for the elucidation of compound induced PDIA6 interactions by AP-MS and label free quantifiaction experiments to assess compound dependent UPR activation

PROJECT DESCRIPTION:
Cysteine-reactive electrophilic compounds remodel the proteome by modulating cellular proteostasis processes

SAMPLE PROCESSING:
AP-MS samples were prepared using Ni-NTA resin for His pulldown of PDIA6-His. Samples were treated with vehicle, compound, or control compound followed by lysis and added TCEP or not. Pulldown was done and elutions prepped for LC-MS/MS analysis using SP3 bead cleanup. Samples assessing UPR activation were treated then prepped for LC-MS/MS using SP3 bead cleanup. Samples were run on a 70 minute gradient (nLC1200) followed by MS/MS analysis on an Orbitrap Eclipse

DATA PROCESSING:
files were searched using FragPipe21 (MSFragger v4.0; Philosopher v5.1.0). Data was further processed using Persues for filtering and imputation
