ABSTRACT:
The dataset contains raw data, peakfiles used for the database searches, as well as search results for the crosslinking LC-MS/MS data

PROJECT DESCRIPTION:
Thianthrenium chemistry for identification of protein−protein interactions in cells

SAMPLE PROCESSING:
Confluent HEK cells were treated with the alkyne-containing thianthrenium reagent, washed 3 times with PBS, and lysed. The lysates were introduced into a CuAAC reaction with biotin-azide, reduced with TCEP, alkylated with chloracetamide, and trypsin-digested on magnetic beads (SP3 protocol). The digested peptides were enriched using NeutrAvidin beads and submitted for XL-LC-MS/MS analysis.

DATA PROCESSING:
Modification search was performed using MaxQuant 2.6.3.0. The crosslink search was performed using XiSearch 1.8.7 and the results were filtered with xiFDR 2.3.5 using 1% threshold on the residue pair level for the intramolecular crosslinks and 1% threshold on both residue pair and protein pair levels for intermolecular crosslinks.
