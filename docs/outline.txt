THREE CORE MESSAGES
-------------------
M1  Metadata annotation has an intrinsic difficulty floor. Expert annotators
    disagree, and disagreement concentrates in the fields the manuscript
    states least often.
M2  Pipeline structure determines extraction reliability more than model
    choice does.
M3  Grounding and validation keep hallucination measurably in check, and the
    cost of that control can be quantified.

SECTION 2. FRAMEWORK ARCHITECTURE
--------------------------------------------------------------------------------
Input: I12, I14. Descriptive section, no performance claims.

2.1 Corpus preparation
    - License verification per manuscript under copyright terms.
    - Section isolation: abstract and Materials and Methods extracted as
      plain text. Justification for the restriction (long-context retrieval
      degradation; Liu et al. 2023, Chroma Research 2025).
    - NOTE: the restriction is now a more exposed design choice than in the
      full paper, because there is no raw-data stream to compensate for
      information sitting in Results or supplementary material. Either add an
      ablation arm reading the full text (see Section 3.1, optional arm S5-FT)
      or defend the restriction explicitly as a limitation.

2.2 Four-layer architecture within DocETL
    - Extraction -> integration -> normalization -> validation.
    - INTEGRATION LAYER DECISION REQUIRED: the current three-way conflict
      resolution compares LLM, METI, and PRIDE values. Without METI this
      becomes a two-way LLM-vs-PRIDE comparison. Options:
        (i) retain a two-source integration layer (labels AGREE, DISAGREE,
            LLM_ONLY, PRIDE_ONLY, UNKNOWN) and report it;
        (ii) drop the integration layer entirely and present a three-layer
            architecture.
      Option (i) preserves the source-attribution argument in the Discussion
      and keeps repository-derived evidence in scope. Recommended.

2.3 Three specialized agents
    Biological agent fields: species, tissue, cell type, cell line, disease
      state, sample source, age, sex, BMI, strain, anatomic site of tumor.
    Technical agent fields: instrument, fragmentation method, ionization type,
      labeling strategy, cleavage agent, enrichment method, fractionation
      method, acquisition method, collision energy, reduction reagent,
      reduction concentration, alkylation reagent, alkylation concentration.
    Experimental design agent fields: experimental design type, factor value,
      number of samples, number of fractions, biological replicate
      identifiers, technical replicate identifiers, number of biological
      replicates, number of technical replicates.
    - Schema fixes the returned field set and requires every field to be
      populated with a value or with unknown.

2.4 Chain-of-thought extraction protocol
    - Two-element [value, evidence] output per field; unmentioned fields
      returned as ["unknown", ""].
    - Verbatim mode: evidence sentence must contain the value as exact
      substring.
    - Inferred mode: evidence prefixed "inferred: " followed by the licensing
      sentence. Worked example (Homo sapiens from patient samples).
    - Restricted inference cases for biological and technical agents:
      (i) species from patients, donors, characterized cell lines;
      (ii) tissue origin from cancer type names; (iii) disease state from cell
      line identity; (iv) label-free in the absence of reported labeling.
    - Broader inference for the experimental design agent.
    - Controlled vocabulary for experimental design type: treated vs control,
      case vs control, time course, dose response, cross-sectional,
      longitudinal.
    - Default value rules: number of fractions defaults to 1 when no
      pre-fractionation described; number of biological replicates defaults
      to 1 when none implied.

2.5 Structural validation and retries
    - Per-agent structural rules (two-element list conformance; non-empty
      evidence on key valid values). Per-agent field lists as in current
      Methods.
    - Up to two automatic retries correcting only the failing fields.

2.6 Gleaning
    - Triggered only when a valid extracted field lacks supporting evidence.
      Corrective, not routine.
    - Up to two rounds. Per-round checks: evidence completeness; exact
      substring match for verbatim evidence; replacement of missing evidence
      with an "inferred: "-prefixed quote. Experimental design agent adds
      exact numeric count checks, collapsing of multi-element lists, and
      inference-prefix validation.
    - Returns VALID when no issues remain.

2.7 Ontology normalization
    Input: I14
    - Field-to-ontology mapping: species and organism -> curated 32-organism
      NCBITaxon subset; cell type -> CL; cell line -> CLO; tissue and organ ->
      UBERON; disease and disease state -> Mondo; instrument, labeling
      strategy, fractionation method -> PSI-MS CV; PTMs -> Unimod; sample
      source -> BTO.
    - Explicitly unmapped fields: fragmentation method, ionization type,
      acquisition method, cleavage agent, enrichment method, collision energy,
      reagent concentrations, all experimental design fields.
    - Graph representation: DAG per ontology; ancestor traversal to
      configurable depth; lowest-common-ancestor lookup for candidate
      disambiguation.
    - Two independent lookup structures: case-insensitive exact
      name-to-identifier index over primary names and synonyms (used by the
      cross-field consistency checker, no embedding call); FAISS embedding
      index (used for fuzzy matching during normalization). Never
      interchanged.
    - Abbreviation handling: build-time synonym injection for binomial
      patterns (single-letter genus prefix form and dot-separated full-genus
      form); query-side expansion of dot-separated binomials for indices
      cached before injection existed; both original and expanded query
      searched, higher similarity returned.
    - Runtime custom synonym registration: in-memory graph append, FAISS
      append, persistence to custom_synonyms.json, automatic reload on
      subsequent runs.
    - Embedding model: SapBERT (cambridgeltl/SapBERT-from-PubMedBERT-fulltext),
      [CLS] representation, max length 128 tokens, batch size 64. Index built
      once offline and serialized; GPU with CPU fallback.
    - Many-to-one surface-form-to-identifier mapping.
    - Index type: IVF + 8-bit scalar quantizer for ontologies with >= 10,000
      indexed surface forms (notably CLO), centroids min(4096, N // 30);
      exact flat inner-product index for smaller ontologies.
    - Query time: top-five candidates by cosine similarity, top candidate used
      downstream, remainder retained in the record for inspection or
      reranking. Accepted as normalized above 0.70; high confidence >= 0.90;
      medium 0.70 to 0.89. Below threshold, free text retained with
      is_normalized: false.
    - Output format: normalized fields become structured objects (original
      value, evidence, ontology identifier, canonical term, similarity score);
      unnormalized fields retain the [value, evidence] list with
      is_normalized: false.

2.8 Hallucination detectors
    - Cross-field ontology consistency, four checks:
        cell line-species via CLO derives_from linked to NCBITaxon, compared
          against extracted species at fuzzy threshold 0.85;
        cell line-tissue via the same relationship, BTO mapped to UBERON;
        disease-tissue via DOID located_in to UBERON;
        cell type-tissue via CL part_of to UBERON.
      Requires normalized identifiers on both sides; unnormalized fields
      skipped. Flags carry mismatch type, both field names and values, both
      identifiers, and the ontology-derived expected value.
    - Negation detection: NegEx via negspacy over a spaCy en_core_web_sm
      dependency parse; extracted value injected as a named entity into its
      evidence sentence; scope determined against negation triggers. Excluded:
      fields inherently defined by absence (label-free) and inferred-evidence
      cases. Flag type negated_evidence.
    - Numeric mismatch: numeric value must appear as exact substring of its
      evidence quote. Recognized patterns: molar concentrations (mM, uM, nM),
      mass quantities (mg, ug, ng, mg/ml), collision energies (NCE, eV, kV),
      mass values (Da, kDa), temporal and rotational units (min, h, RPM).
      Strictly exact matching. Inferred-evidence fields excluded. Flag type
      numeric_mismatch.
    - All flags aggregated into _hallucination_flags at the same record level
      as the extracted fields.

2.9 Model configuration
    - Benchmarked models and version strings (reconcile per Part A open item).
    - Temperature optimization for locally deployed models; temperature 0
      selected for deterministic output; default settings for API models.
      State which models this applied to consistently across Results and
      Methods.

SECTION 4. ONTOLOGY GROUNDING TURNS TEXT INTO QUERYABLE DATA AND CHANGES HOW
           PERFORMANCE MUST BE MEASURED
--------------------------------------------------------------------------------
Input: I11, I14

4.1 Why exact string matching underestimates recovery
    - Worked examples: Q Exactive HF-X vs Q Exactive HF; trypsin vs Trypsin/P;
      liver vs hepatic tissue; human vs Homo sapiens.

4.2 Five-level hierarchical matching strategy
    Level 1 exact match (rank 1): character-for-character.
    Level 2 normalized match (rank 2): case-folding, whitespace trimming.
    Level 3 ontology match (rank 3): both values resolved to identifiers via
      the SapBERT normalizer; identical identifiers equivalent regardless of
      surface form.
    Level 4 hierarchical ontology match (rank 4): shared DAG ancestor,
      bidirectional, score decaying with graph distance, never exceeding four
      hops. Applied to fields with a defined namespace in
      FIELD_ONTOLOGY_MAP (CL, UBERON, Mondo). Cell type fallback: LLM value
      matching a curated cell line lookup is first mapped to its canonical
      cell type (HeLa -> epithelial cell; Jurkat -> T cell) before SapBERT.
    Level 5 semantic match (rank 5): SciBERT embeddings via
      SentenceTransformers with L2 normalization; cosine similarity >= 0.75
      recorded as SEMANTIC with the similarity used as score; below 0.75
      recorded as NO_MATCH with similarity retained for diagnostics.
      Embeddings cached within a benchmark run.

4.3 Effect on measured performance
    - Gemma 4 31B on I11: overall F1 0.424 (exact) to 0.940 (full semantic).
      Biological 0.350 to 0.942; technical 0.421 to 0.921; experimental design
      0.500 to 0.958. Precision improved more than recall in every class
      (overall precision 0.997, recall 0.891).
    - Interpretation: most of the exact-match penalty came from values correct
      but differently expressed, not from absent or wrong values. The largest
      gain in biological fields reflects synonymy and granularity mismatch in
      organism, tissue, and disease terminology, so this is where semantic
      matching corrects the most measurement, not where the model performs
      worst.

4.4 Grounding as resource construction, not only measurement correction
    - Each normalized value retains original text, evidence, identifier,
      canonical term, similarity score. Sub-threshold values retained as free
      text with is_normalized: false so uncertain mappings are never silently
      treated as curated annotations.
    - Report the normalization success rate per field: fraction of extracted
      values reaching high confidence, medium confidence, and sub-threshold.
      This is a resource-quality number the current draft does not report.

SECTION 5. HALLUCINATION IS CONSTRAINED BY EVIDENCE PAIRING AND MEASURABLE
           WITHOUT A MODEL JUDGE                                          [M3]
--------------------------------------------------------------------------------
Input: I2, I6, I11, I12. No LLM judge anywhere in this section.

5.1 Mechanical grounding failures (fully deterministic, no adjudication)
    Input: I11 outputs across all staircase arms
    - Rate of values labeled verbatim that are not an exact substring of their
      evidence sentence.
    - Rate of non-unknown values with empty evidence.
    - Reported per model and per arm. Directly measures whether the evidence
      constraint holds under load, and is the cleanest evidence that removing
      the constraint degrades grounding.

5.2 Non-mentioned-field false positives (grounded in human annotation)
    Input: I6 text-mention flags, I2 papers, extraction output on the same
    papers
    - For any field a human annotator marked as not stated in the text, a
      non-unknown verbatim extraction is a defensible hallucination.
    - PREREQUISITE: quantify the I2 / I11 overlap. If large, report as a panel
      of the benchmark figure. If small, run and report as a standalone
      analysis on the 27 papers and state the set explicitly.
    - Stronger evidence than a model judge, because the reference is human
      annotation.
    - Report separately for verbatim-labeled and inferred-labeled values; an
      inferred value on a non-mentioned field is a different phenomenon and
      should not be pooled with a fabricated verbatim value.

5.3 Detector firing rates and detector precision
    Input: I11, plus manual review of flagged cases
    - Firing rate per detector (cross-ontology, negation, numeric mismatch),
      per field, per model.
    - Precision of each detector against manual review of every flagged case,
      or a sample if volume requires. A detector that fires often and is
      usually wrong is worse than no detector; reporting precision is what
      makes the control claim credible.
    - Note explicitly that these detectors are diagnostics rather than
      pipeline layers: ablating them does not change extracted values, so they
      are evaluated as detectors and not as staircase arms.

5.4 Gleaning effect, quantified
    Input: I11 gleaning logs
    - Number of fields entering gleaning, and why (trigger condition).
    - Repaired: value retained and evidence supplied.
    - Converted: bare value paired with inferred-prefixed evidence.
    - Demoted: value withdrawn to unknown.
    - Rounds required (one versus two), and residual failures after two
      rounds.

5.5 Blinded manual adjudication
    Input: stratified sample of 200 to 300 extracted values from I11 across
    arms and models, plus I12 source text
    - Two annotators, blinded to arm and model.
    - Categories: supported verbatim; supported by defensible inference; not
      supported by the provided text; wrong value; type mismatch.
    - Report inter-adjudicator agreement, since this section is about
      annotation reliability and the adjudication must meet the same standard.
    - This replaces the model judge with the thing the judge was standing in
      for, depends on no external collaborator, and will be weighted above an
      LLM judge by reviewers.

5.6 Unknown rate as the cost of control
    - Cross-reference 3.2(c). The framework's conservatism has a price; state
      it as a number rather than as a policy description.

================================================================================
PART C. DISCUSSION STRUCTURE
================================================================================

D1  What was built and what the results show.
    Framework over model, quantified by the staircase and the crossover.
    Keep the argument that ontologies and community standards become more
    rather than less important as models improve, since the output must be
    anchored to shared structure to be comparable across datasets.

D2  Annotation difficulty is intrinsic to the source material.
    Ties Section 1 to Sections 3 and 5. The fields humans agree on least are
    the fields the manuscript states least and the fields extraction grounds
    least reliably. Same ordering in three independent analyses.
    NOTE: the sharpest version of this argument (37% of the expert-curated
    SDRF reference not connectable to manuscript text) is lost with the judge.
    See Part D for whether any part of it is salvageable.

D3  Hallucination control has to be designed in and measured.
    Provenance, evidence type, confidence, and human-versus-machine origin
    stay attached to every value and remain distinguishable at reuse. A
    confidently extracted wrong value is more harmful than a missing one
    because it is acted upon rather than investigated. Machine-extracted
    metadata should carry less authority than expert annotation, and that
    difference should be encoded in the record rather than left to convention.

D4  Open access as a precondition.
    Reconstruction depends on reading the manuscript, so a dataset deposited
    under an open license but described only behind a paywall is not open in
    the sense that matters for reuse. Interpretive context should travel with
    the deposit.

D5  Relation to SDRF-Proteomics and curation workflows.
    Backfill for pre-standard datasets; pre-population for submitters to
    verify; conflict labels and confidence scores for curator triage. Triage
    and acceleration, not a substitute for standards or expert judgement.
    Cite the lesSDRF finding that experimental design metadata often rests on
    knowledge the authors hold directly.

D6  Limitations, each pointing to further work.
    - Access and licensing bound what can be mined.
    - Abstract and Materials and Methods restriction; state as a limitation or
      resolve with the S5-FT arm.
    - Manuscripts omit replicate structure, sample-to-file mappings, and
      fractionation schemes; the pipeline reports unknown rather than forcing
      an annotation.
    - Records are SDRF-like rather than complete SDRF files, because text
      mining often cannot resolve information at the individual run level;
      values are reported at experiment or project level when finer
      granularity is unavailable.
    - Experimental design remains hardest for humans and machines alike.
    - Raw-data-derived technical evidence is outside the present scope; state
      as a direction, not as a companion paper the reader must wait for.
    - Automated metadata does not replace expert review in high-stakes
      analyses; the output is an evidence-linked prioritization layer.

D7  Outlook.
    Submission-time capture; extension to crosslinking MS, HDX,
    metaproteomics; transfer of the evidence-integration principles to
    metabolomics and other omics domains; closed feedback loop returning
    curator corrections to prompts, normalization rules, and the benchmark
    corpus.
